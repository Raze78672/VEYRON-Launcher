# VeyronLauncher website

Static animated showcase website for VeyronLauncher.

## GitHub Pages
This repository includes a workflow at `.github/workflows/deploy-website.yml`.
After the workflow is committed, open **Settings → Pages** and set **Source** to **GitHub Actions**. Pushes to `main` that change `website/**` will publish the site.

## Feedback
The feedback form opens a pre-filled issue at https://github.com/Raze78672/VEYRON-Launcher/issues/new.
Visitors can review before posting. A GitHub account is required and submitted issues are public.
